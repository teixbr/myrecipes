# MyRecipes

A personal, offline iPhone recipe app: web, photo and social import, a block-based recipe builder,
timers, tools, a shopping list, a cooking log and JSON export. No servers, no running costs.

- `docs/HANDOFF.md`: every decision so far (start here)
- `CLAUDE.md`: rules for Claude sessions working on this repo
- `Resources/tools.json`: built-in catalogue of 205 kitchen tools
- `design/`: source of the direction-D screens. Open the live canvas from the link in the hand-off.
